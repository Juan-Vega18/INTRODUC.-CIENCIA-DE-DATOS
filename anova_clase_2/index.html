Teoria estadistica: ANOVA de dos factores

El ANOVA de dos factores permite evaluar simultaneamente si dos variables independientes explican cambios en una variable respuesta cuantitativa. En este caso: Factor A = operador y Factor B = jornada.

  • Diseno de bloques al azar: una observacion por celda (sin replicacion).
  • Modelo: Yij = mu + alphai + betaj + epsilonij.
  • Supuestos: independencia, normalidad y homogeneidad de varianzas.

Desarrollo del problema

Enunciado

Una fabrica de muebles evalua la productividad (sillones terminados) considerando 5 operadores (Jose, Carlos, Ximena, Karla y Manuel) y 4 jornadas (1, 2, 3 y 4).

Hipotesis

Operadores (Factor A):

  • H0: las medias de productividad de todos los operadores son iguales.
  • H1: al menos un operador tiene media distinta.

Jornadas (Bloques):

  • H0: las medias de productividad de las 4 jornadas son iguales.
  • H1: al menos una jornada presenta media distinta.

Calculos clave

  1. GL operadores = c - 1 = 5 - 1 = 4.
  2. GL jornadas = r - 1 = 4 - 1 = 3.
  3. GL error = (c - 1)(r - 1) = 4 x 3 = 12.
  4. CM operadores = 205.80 / 4 = 51.45.
  5. CM jornadas = 116.20 / 3 = 38.73.
  6. CM error = 95.80 / 12 = 7.98.
  7. F operadores = 51.45 / 7.98 = 6.45.
  8. F jornadas = 38.73 / 7.98 = 4.85.

Codigo Python para resolver el ejercicio

Puedes descargar el script anova2_solver.py, que resuelve ANOVA de dos factores (sin replicacion) desde la matriz de datos o desde SC resumidas.

Descargar anova2_solver.py

from anova2_solver import REPORTED_SUMMARY, solve_from_summary

result = solve_from_summary(REPORTED_SUMMARY)

print("F operadores:", round(result["f_operators"], 4))
print("F jornadas:", round(result["f_days"], 4))
print("p operadores:", result["p_operators"])
print("p jornadas:", result["p_days"])
print("Rechazar H0 operadores:", result["reject_operators"])
print("Rechazar H0 jornadas:", result["reject_days"])

Interpretacion y conclusion

  • Operadores: Fc = 6.45 > Ft(4,12) ~ 3.26.
  • Jornadas: Fc = 4.85 > Ft(3,12) ~ 3.49.

Con alpha = 0.05, se rechaza H0 para ambos factores: existe evidencia de diferencias significativas entre operadores y tambien entre jornadas.

A partir de las medias observadas, Ximena destaca como la operadora con mayor productividad media y la Jornada 2 presenta el mejor rendimiento promedio.
