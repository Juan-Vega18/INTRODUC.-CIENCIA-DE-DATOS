Teoría estadística (ANOVA de un factor)

El ANOVA de un factor determina si existen diferencias significativas entre las medias de tres o más poblaciones. En este caso, el factor es el método de ensamblado y la variable respuesta es el tiempo promedio (minutos).

Conceptos clave

  • Factor: variable independiente controlada por el investigador.
  • Niveles o tratamientos: Alfa, Beta, Gamma y Sigma.
  • Error experimental: variabilidad que no se explica por el método aplicado.

Supuestos del modelo

  • Normalidad de las poblaciones.
  • Igualdad de varianzas (homocedasticidad).
  • Independencia entre observaciones.

Modelo aditivo: Yij = μ + τi + εij.

Desarrollo del problema

Enunciado y datos

Se evaluaron 4 métodos (k = 4), con 5 repeticiones por método (N = 20). Medias muestrales:

  • Alfa: 60.4 min
  • Beta: 55.6 min
  • Gamma: 65.2 min
  • Sigma: 64.6 min

Pregunta: ¿existen diferencias significativas entre los tiempos promedio al 5%?

Hipótesis nula (H₀): μ₁ = μ₂ = μ₃ = μ₄
Hipótesis alternativa (H₁): al menos una media es distinta.

Tabla ANOVA

Entre grupos (tratamientos) k - 1 = 3 296.55 98.85 13.587
Dentro de grupos (error) N - k = 16 116.40 7.275 -
Total N - 1 = 19 412.95 - -

Cálculo paso a paso

  1. Grados de libertad: GLentre = 4 - 1 = 3 y GLdentro = 20 - 4 = 16.
  2. Cuadrados medios: CMentre = 296.55 / 3 = 98.85 y CMdentro = 116.40 / 16 = 7.275.
  3. Estadístico: Fc = 98.85 / 7.275 = 13.587.

Código Python para resolver el problema

El sitio incluye el archivo anova_solver.py (descargable) para resolver este ANOVA a partir de la tabla resumen, sin dependencias externas.

Descargar anova_solver.py 

from anova_solver import AnovaInput, solve_anova

means = {"Alfa": 60.4, "Beta": 55.6, "Gamma": 65.2, "Sigma": 64.6}
result = solve_anova(
    AnovaInput(k=4, n_total=20, ss_between=296.55, ss_within=116.40, alpha=0.05)
)

print(result)
print("Metodo mas rapido:", min(means, key=means.get))

Análisis e interpretación

  • F calculado: 13.587
  • F crítico (α = 0.05, GL 3 y 16): ≈ 3.24
  • Valor p: ≈ 0.000115

Como Fc > Ft y p < 0.05, se rechaza H₀. Existe evidencia estadística para afirmar que los tiempos promedio no son iguales.

En estos datos, Beta presenta el menor tiempo promedio (55.6 min), por lo que aparece como el método más eficiente.
