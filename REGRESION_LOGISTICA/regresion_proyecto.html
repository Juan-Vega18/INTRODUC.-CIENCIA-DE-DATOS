Sección 01
01

¿Qué es la Regresión Logística?

La regresión logística es un modelo estadístico supervisado utilizado para predecir la probabilidad de ocurrencia de un evento binario. A diferencia de la regresión lineal, cuya variable respuesta es continua, la regresión logística modela una variable dependiente que toma únicamente dos valores posibles: 0 o 1 (éxito/fracaso, sí/no, presente/ausente).

El modelo no predice directamente la clase, sino la probabilidad de pertenecer a ella. Esta probabilidad queda restringida al intervalo [0, 1] gracias a la función sigmoide, también llamada función logística.

Función Logística (Sigmoide)

p(x) = 1 / (1 + e−(β₀ + β₁·x))

Transformación Logit

Para linealizar el modelo se aplica la función logit, que es el logaritmo de la razón de probabilidades (odds ratio):

logit(p) = ln( p / (1−p) ) = β₀ + β₁·x

¿Cuándo se usa?

Se emplea cuando la variable respuesta es dicotómica: predecir si un correo es spam, si un cliente comprará, si un paciente tiene una enfermedad, o —como en este caso— si un estudiante obtendrá matrícula de honor. El predictor puede ser continuo, discreto o categórico.

Los coeficientes β₀ (intercepto) y β₁ (pendiente) se estiman por máxima verosimilitud (MLE), maximizando la probabilidad de observar los datos dados. La significancia del modelo se evalúa mediante el Likelihood Ratio Test y la de cada coeficiente mediante la prueba de Wald.

Sección 02
02

Ejemplo Realizado: Problema y Metodología

El objetivo del trabajo fue reconstruir y comparar modelos de regresión logística simple para predecir la probabilidad de que un estudiante obtenga matrícula de honor en función de su nota en matemáticas.

La variable dependiente es binaria: matricula = 1 (obtiene matrícula de honor) o matricula = 0 (no la obtiene). El predictor continuo es matematicas, la puntuación del estudiante en esa asignatura.

Tres enfoques comparados

① Estimado desde imagen

Puntos extraídos de la gráfica original del paper usando análisis de imagen con ChatGPT. Modelo ajustado sobre datos aproximados.

② Datos originales

Modelo ajustado usando el dataset original del paper. Referencia de verdad para evaluar la calidad del modelo estimado.

③ Modelo oficial

Coeficientes publicados en el sitio web de referencia (cienciadedatos.net). Sirve como validación del modelo reconstruido con datos originales.

El experimento buscó responder: ¿qué tan bien puede recuperarse un modelo estadístico únicamente a partir de la imagen de su gráfico? Esta pregunta tiene relevancia práctica en contextos donde los datos originales no están disponibles.

Sección 03
03

Obtención de Datos

El proceso de obtención de datos fue uno de los elementos más innovadores del trabajo. Se tomó la imagen original de la gráfica de regresión logística publicada en el paper de referencia y se subió a ChatGPT, solicitando un análisis visual de la imagen.

ChatGPT realizó un análisis de imagen e identificó la posición aproximada de cada punto (observación) en el plano, estimando sus coordenadas (nota de matemáticas, valor binario de matrícula) y la forma de la curva logística. Este proceso generó los datos del primer dataset: regresion_logistica_estimacion.csv.

Paralelamente, se accedió al dataset original utilizado en el paper, disponible en el repositorio del sitio de referencia, generando el segundo dataset: datos_regresion_logistica_originales.csv.

Estimación de Modelos

Se estimaron dos modelos de regresión logística usando la librería statsmodels de Python, que permite ajuste por máxima verosimilitud con estadísticas completas de inferencia.

Modelo 1 — Datos estimados (ChatGPT)

# ========================= MODELO CON PUNTOS AZULES =========================

# Filtrar puntos azules
df_puntos = df[df["tipo"] == "punto_azul"].copy()

# Variables
X1 = sm.add_constant(df_puntos["matematicas"])  # agrega intercepto β₀
y1 = df_puntos["matricula"]

# Ajustar regresión logística
modelo_puntos = sm.Logit(y1, X1).fit()

print(modelo_puntos.summary())

# Extraer coeficientes
b0_1 = modelo_puntos.params["const"]
b1_1 = modelo_puntos.params["matematicas"]

print(f"logit(p) = {b0_1:.4f} + ({b1_1:.4f})·matematicas")
logit(p) = −4.5644 + 0.0751·matemáticas

p(x) = 1 / (1 + exp(−(−4.5644 + 0.0751·x)))

Modelo 2 — Datos originales del paper

# ========================= MODELO CON DATOS ORIGINALES =========================

X = df_original["matematicas"]
y = df_original["matricula"]

# Agregar intercepto β₀
X = sm.add_constant(X)

# Regresión logística por MLE
modelo = sm.Logit(y, X)
resultado = modelo.fit()

print(resultado.summary())

b0 = resultado.params["const"]
b1 = resultado.params["matematicas"]

print(f"logit(p) = {b0:.4f} + ({b1:.4f})·matematicas")
logit(p) = −9.7939 + 0.1563·matemáticas

Observaciones clave

El modelo reconstruido con los datos originales coincide de forma casi exacta con el modelo oficial del sitio web (diferencia en β₁ inferior a 0.0001). El modelo estimado desde la imagen difiere notablemente en sus coeficientes, pero visualmente las curvas son sorprendentemente similares en su forma general. Las diferencias más visibles aparecen en la zona de probabilidades intermedias (x ≈ 55–65) y en la rapidez de transición hacia probabilidades altas.

Sección 06
06

Conclusiones

Importancia de la Regresión Logística

La regresión logística es uno de los algoritmos fundamentales de la ciencia de datos. Su interpretabilidad, solidez estadística y eficiencia computacional la hacen irreemplazable en medicina, finanzas, marketing y ciencias sociales. Comprender sus fundamentos es esencial para cualquier científico de datos.

Precisión de la Reconstrucción

El modelo estimado a partir de la imagen recuperó la forma sigmoide y la dirección del efecto, pero con coeficientes distintos (β₁: 0.0751 vs. 0.1563). Esto indica que la reconstrucción visual capta la tendencia cualitativa, pero pierde precisión cuantitativa, especialmente en la pendiente.

Diferencias entre Modelos

El modelo original tiene una pendiente ~2× más pronunciada, lo que implica una transición más rápida entre probabilidades bajas y altas. El modelo estimado subestima las probabilidades para notas altas (error% supera el 300% en la zona de x ≈ 70+), mientras que en notas bajas la diferencia es moderada (<60%).

Relevancia en Ciencia de Datos

Este experimento demuestra que los datos de entrenamiento son determinantes en la calidad de cualquier modelo. La disponibilidad y calidad del dataset impacta directamente los coeficientes estimados. En contextos reales, depender de datos aproximados puede llevar a decisiones subóptimas, subrayando la importancia de la recolección rigurosa de datos.

El experimento valida además el potencial —y los límites— de usar inteligencia artificial generativa (ChatGPT) como herramienta de extracción de datos desde representaciones visuales. Aunque la IA logró reproducir correctamente la estructura del problema y la tendencia general del modelo, no puede reemplazar la precisión de los datos originales para una estimación estadística rigurosa.
